dev-in-situ

1 · Connect

Run npm start in the dev-in-situ folder. It prints a token; paste it here.

2 · Defaults

These are the starting values in the popover. Any change you make there is remembered.

3 · Agents

Stored by the daemon in config.json. Each agent either uses a preset (claude, codex, gemini, opencode, antigravity) or spells out its own command and arguments. Kimi, GLM and Ollama already work through the claude preset. Set their API key as an environment variable before you run npm start.
